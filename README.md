# Линза — честный каталог VPN в Telegram Mini App

Агрегатор VPN-сервисов из Telegram: клиенты ищут и сравнивают VPN по цене и параметрам (как Aviasales, только для VPN), владельцы сервисов сами ведут карточки, а рейтинг строится только по отзывам, переходам и стабильности по сигналам клиентов. Платные места, когда появятся, всегда идут отдельно с пометкой «Реклама» и на рейтинг не влияют.

- Бот: `@linza_app_bot` (запасной — `@getlinza_bot`), приложение: `t.me/linza_app_bot/app`
- Бэкенд: Node.js 22 без зависимостей (`node:http`, встроенный `node:sqlite`, `node:crypto`)
- Фронтенд: ванильный JS (ES-модули, без сборки), дизайн liquid glass, бирюзовый акцент, светлая и тёмная тема Telegram
- Исходный макет дизайна лежит в [`docs/design-reference.html`](docs/design-reference.html)

## Быстрый старт (локально)

Нужен Node.js ≥ 22.13.

```bash
cp .env.example .env          # для локального запуска хватит значений по умолчанию
npm run seed -- --reset       # 25 тестовых VPN, отзывы, переходы, сигналы о статусе, архив топов, 13 каналов биржи рекламы
npm run dev                   # http://localhost:3000/?dev=100001
```

`npm run dev` включает тестовый вход: вне Telegram приложение входит пользователем `100001` (у него роли клиента, владельца «Аврора VPN» и администратора, если `ADMIN_IDS=100001`). Другого пользователя можно выбрать параметром `?dev=<id>`. **На сервере тестовый вход всегда выключен** (`npm start`, `ALLOW_DEV_AUTH=0`).

Тесты: `npm test` (подпись initData, модерация, уведомления, топ месяца, права доступа, HTTP-сценарий от заявки до публикации).

## Запуск на сервере (бот + мини-апп)

Как это выглядит для пользователя: он открывает бота в Telegram, видит описание и жмёт «Старт» — бот присылает приветствие с кнопкой «Открыть Линзу»; ещё одна кнопка «Линза» всегда стоит слева от поля ввода. Мини-апп открывается внутри Telegram. Сервер нужен, чтобы разместить страницу мини-аппа (Telegram требует HTTPS) и принимать сообщения бота.

**Что понадобится**
- VPS на Ubuntu/Debian с root-доступом и **свободным TCP-портом 443** (порт 80 не нужен — сертификат выпускается через 443). Если 443 уже занят VPN (Xray/Reality) или прокси панели, скрипт остановится и покажет, кто его держит: Линзу можно подключить через этот прокси или поставить на отдельный сервер, хватит 1 ГБ RAM.
- Токен бота: @BotFather → `/newbot` → `linza_app_bot` (если занят — `getlinza_bot`).
- Ваш Telegram ID — его покажет @userinfobot.
- Домен, направленный A-записью на IP сервера, — по желанию. Без домена скрипт возьмёт адрес вида `1-2-3-4.sslip.io`.

**Установка**

```bash
git clone -b claude/linza-miniapp https://github.com/UnionUnllimited/ChatUPD1.git linza
cd linza
sudo bash deploy/install.sh
```

Скрипт поставит Docker, спросит токен, ID администраторов и домен, сам проверит токен в Telegram, включит HTTPS и webhook бота и предложит загрузить тестовые VPN. Режим выбирается сам и сохраняется в `.env`:

- **порт 443 свободен** — Линза поднимает свой Caddy и получает сертификат;
- **на 443 уже работает Caddy в Docker** (например, у Remnawave) — приложение подключается к его Docker-сети под именем `linza`, а его Caddyfile дополняется одним из двух способов:
  - домен новый (своя A-запись на этот сервер) — дописывается отдельный сайт `<домен> { reverse_proxy linza:3000 }`;
  - домен уже открывает другой сервис через этот Caddy — Линза встаёт на нём по пути (по умолчанию `/linza`): внутрь блока этого домена добавляются `redir /linza /linza/` и `handle_path /linza/* { reverse_proxy linza:3000 }`, остальное на домене работает как раньше. Мини-апп тогда открывается по `https://<домен>/linza/`.

  Перед правкой делается копия `Caddyfile.bak-linza-…`, конфиг проверяется `caddy validate` и применяется через `caddy reload` без перезапуска. Если проверка или итоговый запрос к Линзе не прошли, файл возвращается байт в байт. Если у нового домена A-запись ведёт не на этот сервер (например, домен обслуживается через frp на другой машине), скрипт предупредит и остановится.

  Убрать Линзу из прокси: удалить строки между `# --- Линза: added…` и `# --- Линза end ---` (правка «на месте», чтобы не сломать монтирование файла) и перечитать конфиг:
  ```bash
  sed '/# --- Линза: added/,/# --- Линза end ---/d' Caddyfile > /tmp/cf && cat /tmp/cf > Caddyfile
  docker exec caddy caddy reload --config /etc/caddy/Caddyfile --adapter caddyfile
  ```

Красивая ссылка `t.me/<бот>/app` (по желанию): @BotFather → `/newapp` → выбрать бота → short name `app` → URL `https://<домен>`.

**Обслуживание**
- Обновить: `git pull && sudo docker compose up -d --build`
- Перейти на свой домен: в DNS домена поставьте A-запись `@` → IP сервера (лишние A и AAAA для `@` удалите), затем `sudo bash deploy/set-domain.sh linza-app.ru`. Скрипт проверит DNS, добавит сайт в Caddy, дождётся сертификата и только после этого переключит бота и мини-апп; при ошибке всё остаётся как было, старый адрес продолжает работать. После — @BotFather → `/myapps` → Edit Web App URL.
- Логи: `sudo docker compose logs -f app`
- Данные (база SQLite и логотипы) лежат в Docker-томе `linza-data`; бэкап: `sudo docker compose cp app:/data ./backup`
- Удалить тестовые VPN перед настоящим запуском: админ-панель → Настройки → «Удалить тестовые данные» (реальные пользователи остаются)

Без Docker: Node.js ≥ 22.13, `.env` по образцу `.env.example`, `npm start` за любым HTTPS-прокси. Без публичного адреса бот может работать long polling'ом (`BOT_POLLING=1`, `BOT_WEBHOOK_URL` пустой), но мини-апп всё равно должен открываться по HTTPS.

## Что есть в первой версии

**Клиент**
- **Подобрать VPN за 30 секунд:** пять вопросов в одно касание (устройство, сколько устройств, белые списки на мобильном, способ оплаты, бюджет) → три лучших варианта с отличиями и «Все подходящие» в каталоге с теми же фильтрами. Сервисы с массовым сбоем не рекомендуются.
- «Поделиться» на карточке VPN: ссылка `t.me/<бот>/app?startapp=s_<id>` открывает этот VPN сразу в Линзе.
- Главная: поиск, быстрые фильтры «Дешёвые» / «С триалом» / «Оплата картой РФ», топ-10 месяца, «Скидки и акции», средняя цена рынка.
- Каталог: фильтры (цена от–до, триал, протокол, страны, устройства, оплата, платформы, белые списки, ниже рынка, акции), строка применённых фильтров со снятием в одно касание, сортировки по цене, рейтингу, популярности и новизне. Число результатов пересчитывается прямо в шторке фильтров.
- Карточка: тарифы на 1/3/6/12 месяцев с выгодой, все параметры, метка «ниже / в / выше рынка», статус «Проверено администратором» с датой и историей проверок, акция с промокодом, отзывы. Главная кнопка Telegram — «Перейти в бот» (через `openTelegramLink`).
- **Статус по сигналам клиентов:** на карточке кнопки «Работает у меня» / «Не работает у меня» и необязательный выбор сети (Wi-Fi, МТС, Билайн, МегаФон, Tele2). Видно текущий статус, время последнего сигнала, полосу доступности за 30 дней (касание по дню — подробности), разбивку по сетям, когда данных достаточно, и отметку «Проверено администратором». В списке — значок статуса.
- Сравнение до 3 VPN с подсветкой различий и режимом «Только различия».
- Профиль: избранное, мои отзывы (изменить/удалить), история переходов (отсюда же — отзыв), настройки уведомлений, переключение роли «Клиент / VPN-сервис».

**VPN-сервис**
- «Добавить VPN» → заявка → ручное подтверждение владения администратором → кабинет.
- Редактор карточки и тарифов (логотип уменьшается в браузере до 256 px). Любое изменение уходит на модерацию; до одобрения клиенты видят прежнюю версию. Статусы «На проверке / Опубликовано / Отклонено» с причиной.
- Акции со сроком действия: модерация, автоматическое снятие по окончании.
- Статус по сигналам: полоса доступности, сводка голосов за окно и по сетям, уведомление в бот при «Есть сообщения о сбоях» / «Массовый сбой», кнопка **«Оспорить»** (спор уходит администратору).
- Статистика: показы и переходы по дням (графики + таблица), конверсия, избранное, средняя оценка, место в текущем расчёте топа и балл по составляющим.

**Биржа рекламы** — админы Telegram-каналов продают рекламу, владельцы VPN покупают. Сейчас бесплатно, сделка идёт напрямую в Telegram; гарант встанет на сделки позже.
- Три роли: клиент, владелец VPN, продавец рекламы. При первом запуске человек выбирает, кто он; роль меняется в профиле.
- Продавец заполняет канал, тематику, подписчиков, охват за 24 и 48 ч (со ссылкой на Telemetr/TGStat — иначе пометка «со слов продавца»), форматы 1/24, 2/48, 1/48, закреп, пакет каналов с ценами, свободные даты в календаре, были ли VPN-размещения, контакт. Линза сама считает CPM = цена ÷ охват × 1000 и красит его светофором: до 250 ₽ — выгодно, до 350 ₽ — норма, дороже — дорого (пороги в админке).
- Лента с фильтрами (тематика, охват, цена, CPM до, формат, свободная дата, только подтверждённые, уже были VPN-размещения) и сортировкой (дешёвый CPM, охват, рейтинг), избранные каналы.
- Защита без гаранта: продавец добавляет бота Линзы админом канала — появляется галочка «канал подтверждён», число подписчиков и аватар берутся из Telegram, а чужие объявления того же канала снимаются; рейтинг ставят только покупатели, чьё размещение состоялось; жалобы от нескольких покупателей снимают канал на проверку.
- Сделка: «Забронировать» (формат, дата, свой VPN, комментарий) → продавцу приходит заявка в бот → он согласует или отклоняет → обоим открываются контакты → через 48 ч после даты бот просит покупателя оставить отзыв (сколько пришло, сколько оплат, совпал ли охват). «Мои сделки»: Заявка → Согласовано → Опубликовано → Отзыв.
- В админке — раздел «Биржа рекламы»: каналы, жалобы, снятие и возврат, ручное подтверждение, настройки CPM и жалоб.

**Админ-панель** — отдельная страница `https://<домен>[/путь]/admin/` (широкая раскладка с боковым меню, работает и на телефоне, и внутри Telegram):
- **Вход в браузере:** отправьте боту `/admin` — он пришлёт одноразовую ссылку (10 минут), сессия живёт 7 дней, «Выйти на всех устройствах» — в настройках. Из мини-аппа: Профиль → «Админ-панель». Доступ только у `ADMIN_IDS` и назначенных в панели админов.
- **Обзор:** пользователи и активность, переходы и отзывы за месяц, очередь модерации, графики по дням, лидеры месяца, состояние очереди бота.
- **Сервисы:** таблица всех карточек с фильтрами и сортировкой; карточка сервиса со статистикой, проверками, версиями и акциями; админ может сам **создать карточку** (для наполнения каталога до прихода владельцев), **править её без модерации**, назначить или сменить владельца, скрыть и удалить.
- **Пользователи:** поиск, роли (назначить/снять админа и VPN-сервис), блокировка, отзывы и переходы пользователя.
- **Статусы:** споры владельцев, аномалии, сервисы со сбоями сейчас и история изменений. Действия: «Снять статус» (с комментарием в журнал; голоса до этого момента больше не учитываются), «Подтвердить», «Проверено» (ставит отметку «Проверено администратором»), для аномалий — «Сигналы честные» / «Аннулировать голоса». На странице сервиса — все голоса с базовым весом, доверием и причиной, если голос не учтён. **Настройки статусов** — отдельный экран со всеми порогами, весами, окнами и лимитами.
- **Модерация, заявки, проверки, топ месяца, журнал** — как раньше, плюс **все отзывы** с возможностью скрыть уже опубликованный.
- **Рассылка** через бота (всем / клиентам / владельцам VPN) с проверкой охвата; пользователи могут отключить «Новости Линзы».
- **Уведомления:** журнал сообщений бота со статусами и ошибками доставки.
- **Настройки:** сглаживание оценки в топе, порог метки рынка, администраторы, сессии, выгрузки CSV (сервисы, пользователи, отзывы, переходы) и кнопка **«Удалить тестовые данные»** перед запуском.

**Бот ведёт каждого по шагам** — что произошло и что делать дальше, с кнопкой прямо в нужный экран:
- владельцу VPN: «заявка принята» → «одобрена, заполните карточку» → «карточка на модерации» → «опубликована, что дальше» (а также правки, акции, новые отзывы о сервисе, статусы по сигналам); через сутки без карточки — одно напоминание;
- клиенту: отзыв опубликован или отклонён с причиной;
- продавцу рекламы: «канал на бирже, подтвердите через бота» (через сутки — напоминание), новая заявка (через сутки без ответа — напоминание), согласование с контактом покупателя, день размещения, оценка покупателя;
- покупателю рекламы: согласование с контактом продавца или отказ, день размещения, «пост вышел», просьба оставить отзыв;
- админам: новые заявки на подключение, карточки и акции на модерации, споры, аномалии, жалобы на каналы.
Если человек открыл Линзу по ссылке и не нажимал «Старт», при подаче заявки, размещении канала или бронировании Telegram спросит разрешение на сообщения от бота.

**Бот** также присылает: снижение цены и новые акции у VPN из избранного, публикацию топа, статусы модерации владельцам, сбои по сигналам — владельцу сервиса, споры и аномалии — администраторам (ссылка ведёт сразу на экран «Статусы»). Сообщения идут через очередь (`notifications`) с ограничением скорости; если бот заблокирован пользователем, рассылка ему прекращается.

## Ключевые правила

| Правило | Как реализовано |
|---|---|
| Честная выдача | Сортировки и топ считаются только из отзывов, переходов и сигналов клиентов о работе. Таблица `ad_placements` для будущих рекламных мест отдаётся API отдельным полем `sponsored` и не участвует в ранжировании. |
| Отзыв только после перехода | `POST /api/services/:id/click` логирует переход с Telegram ID перед `openTelegramLink`; отзыв без записи в `clicks` отклоняется. |
| Топ-10 месяца | Сводный балл = 40% оценки за месяц (сглаженное байесовское среднее, чтобы один отзыв не решал) + 30% уникальные клиенты (нормированы к лидеру) + 30% стабильность — доля времени месяца без статусов «Есть сообщения о сбоях» и «Массовый сбой» (считается по истории `status_changes` с момента публикации). Веса — в `settings`, меняются в админке. Публикуется админом или автоматически 1-го числа в `TOP_AUTOPUBLISH_HOUR_MSK`. Архив — `top_snapshots` / `top_entries`, отсюда бейдж «Топ-10 за <месяц>». |
| Метка цены | Сравнивается цена за 1 месяц (или самый короткий тариф) со средней по видимому каталогу ±10%. Среднее пересчитывается при каждой публикации тарифов и при скрытии/возврате карточек. |
| Статус по сигналам | Окно 2 ч: «Есть сообщения о сбоях» — от 3 голосов «не работает» с суммарным весом от 2, «Массовый сбой» — от 8 с весом от 5, и только если они перевешивают «работает». Статус снимается, когда «работает» перевешивает или через 6 ч без новых сигналов о сбоях. Система никогда не пишет «Не работает». Пересчёт — при каждом голосе и раз в 10 минут. |
| Защита от накрутки | Вес голоса = базовый (1 — если клиент переходил в бот этого VPN через Линзу, иначе 0,3) × доверие аккаунта (`users.trust_score`, 1,0 по умолчанию, 0,1–2,0). Через 2 ч голос сверяется с итоговым большинством и доверие немного растёт или падает; клиенту оно не показывается. Один голос на сервис за 12 ч (новый заменяет старый), не больше 5 сервисов в сутки, голоса аккаунтов моложе 24 ч и владельцев VPN хранятся, но не учитываются. Голосовать можно только из Telegram (подпись initData). Все числа — в «Настройках статусов». |
| Биржа рекламы | Контакт продавца не отдаётся API ленты и карточки — только в согласованной сделке. Подтверждение канала — по событию `my_chat_member` (бот стал админом): публичный канал сверяется по username, закрытый — по названию, и только среди объявлений того, кто добавил бота. Отзыв — только от покупателя сделки и только после даты размещения. |
| Цены | Целые рубли, в `tariffs` хранится полная цена за период. |
| Модерация | Опубликованная версия живёт в `services`, правки — в `service_revisions` (новая отправка заменяет ожидающую). |
| Авторизация | `Authorization: tma <initData>`, подпись проверяется HMAC-SHA256 по токену бота, срок жизни — `INIT_DATA_MAX_AGE`. Роли — открытый список строк в `user_roles`, новые роли добавляются без изменений в авторизации и профиле. |

## Структура

```
server/
  index.js            запуск: HTTP, бот, планировщик
```

## Заложено на следующие версии

- **Рынок услуг**: таблица `market_listings` (`kind`: `hosting`, `job`, `solution`), раздел «Скоро в Линзе» в профиле. Биржа рекламы уже работает (таблицы `ad_*`); гарант встанет на `ad_deals`: деньги замораживаются при согласовании и уходят продавцу, когда пост провисел оговорённый срок. Новые роли — новые строки в `user_roles`.
- **Монетизация**: `ad_placements` (`catalog_top`, `collection_pin`, `highlight`, `home_banner`) с ценой и сроками; API уже отдаёт `sponsored` отдельно от выдачи. Реферальные ссылки — параметр `?start=` поддерживается в ссылке на бот. Платная верификация, продажа подписок и комиссии — после консультации с юристами.
