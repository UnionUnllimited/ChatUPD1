# Линза — честный каталог VPN в Telegram Mini App

Агрегатор VPN-сервисов из Telegram: клиенты ищут и сравнивают VPN по цене и параметрам (как Aviasales, только для VPN), владельцы сервисов сами ведут карточки, а рейтинг строится только по отзывам, переходам и ручным проверкам. Платные места, когда появятся, всегда идут отдельно с пометкой «Реклама» и на рейтинг не влияют.

- Бот: `@linza_app_bot` (запасной — `@getlinza_bot`), приложение: `t.me/linza_app_bot/app`
- Бэкенд: Node.js 22 без зависимостей (`node:http`, встроенный `node:sqlite`, `node:crypto`)
- Фронтенд: ванильный JS (ES-модули, без сборки), дизайн liquid glass, бирюзовый акцент, светлая и тёмная тема Telegram
- Исходный макет дизайна лежит в [`docs/design-reference.html`](docs/design-reference.html)

## Быстрый старт (локально)

Нужен Node.js ≥ 22.13.

```bash
cp .env.example .env          # для локального запуска хватит значений по умолчанию
npm run seed -- --reset       # 25 тестовых VPN, отзывы, переходы, проверки, архив топов
npm run dev                   # http://localhost:3000/?dev=100001
```

`npm run dev` включает тестовый вход: вне Telegram приложение входит пользователем `100001` (у него роли клиента, владельца «Аврора VPN» и администратора, если `ADMIN_IDS=100001`). Другого пользователя можно выбрать параметром `?dev=<id>`. **На сервере тестовый вход всегда выключен** (`npm start`, `ALLOW_DEV_AUTH=0`).

Тесты: `npm test` (подпись initData, модерация, уведомления, топ месяца, права доступа, HTTP-сценарий от заявки до публикации).

## Запуск на сервере (бот + мини-апп)

Как это выглядит для пользователя: он открывает бота в Telegram, видит описание и жмёт «Старт» — бот присылает приветствие с кнопкой «Открыть Линзу»; ещё одна кнопка «Линза» всегда стоит слева от поля ввода. Мини-апп открывается внутри Telegram. Сервер нужен, чтобы разместить страницу мини-аппа (Telegram требует HTTPS) и принимать сообщения бота.

**Что понадобится**
- VPS на Ubuntu/Debian с root-доступом и **свободными портами 80 и 443**. Сервер, где на 443 уже работает VPN (Xray/Reality), не подойдёт — возьмите отдельный, хватит 1 ГБ RAM.
- Токен бота: @BotFather → `/newbot` → `linza_app_bot` (если занят — `getlinza_bot`).
- Ваш Telegram ID — его покажет @userinfobot.
- Домен, направленный A-записью на IP сервера, — по желанию. Без домена скрипт возьмёт адрес вида `1-2-3-4.sslip.io`.

**Установка**

```bash
git clone -b claude/linza-miniapp https://github.com/UnionUnllimited/ChatUPD1.git linza
cd linza
sudo bash deploy/install.sh
```

Скрипт поставит Docker, спросит токен, ID администраторов и домен, сам проверит токен в Telegram, получит HTTPS-сертификат (Caddy), включит webhook бота и предложит загрузить тестовые VPN. При каждом старте сервер настраивает боту описание, команды `/start` и `/help` и кнопку меню «Линза».

Красивая ссылка `t.me/<бот>/app` (по желанию): @BotFather → `/newapp` → выбрать бота → short name `app` → URL `https://<домен>`.

**Обслуживание**
- Обновить: `git pull && sudo docker compose up -d --build`
- Логи: `sudo docker compose logs -f app`
- Данные (база SQLite и логотипы) лежат в Docker-томе `linza-data`; бэкап: `sudo docker compose cp app:/data ./backup`
- Удалить тестовые VPN перед настоящим запуском: `sudo docker compose down && sudo docker volume rm linza_linza-data && sudo docker compose up -d`

Без Docker: Node.js ≥ 22.13, `.env` по образцу `.env.example`, `npm start` за любым HTTPS-прокси. Без публичного адреса бот может работать long polling'ом (`BOT_POLLING=1`, `BOT_WEBHOOK_URL` пустой), но мини-апп всё равно должен открываться по HTTPS.

## Что есть в первой версии

**Клиент**
- Главная: поиск, быстрые фильтры «Дешёвые» / «С триалом» / «Оплата картой РФ», топ-10 месяца, «Скидки и акции», средняя цена рынка.
- Каталог: фильтры (цена от–до, триал, протокол, страны, устройства, оплата, платформы, белые списки, ниже рынка, акции), строка применённых фильтров со снятием в одно касание, сортировки по цене, рейтингу, популярности и новизне. Число результатов пересчитывается прямо в шторке фильтров.
- Карточка: тарифы на 1/3/6/12 месяцев с выгодой, все параметры, метка «ниже / в / выше рынка», статус «Проверено администратором» с датой и историей проверок, акция с промокодом, отзывы. Главная кнопка Telegram — «Перейти в бот» (через `openTelegramLink`).
- Сравнение до 3 VPN с подсветкой различий и режимом «Только различия».
- Профиль: избранное, мои отзывы (изменить/удалить), история переходов (отсюда же — отзыв), настройки уведомлений, переключение роли «Клиент / VPN-сервис».

**VPN-сервис**
- «Добавить VPN» → заявка → ручное подтверждение владения администратором → кабинет.
- Редактор карточки и тарифов (логотип уменьшается в браузере до 256 px). Любое изменение уходит на модерацию; до одобрения клиенты видят прежнюю версию. Статусы «На проверке / Опубликовано / Отклонено» с причиной.
- Акции со сроком действия: модерация, автоматическое снятие по окончании.
- Статистика: показы и переходы по дням (графики + таблица), конверсия, избранное, средняя оценка, место в текущем расчёте топа и балл по составляющим.

**Администратор** (раздел внутри Mini App, только для `ADMIN_IDS`)
- Заявки на подключение, очередь модерации (карточки с «было / стало», акции, отзывы), ручные проверки с историей, топ месяца (предпросмотр любого месяца, веса, публикация, архив), поиск пользователей и сервисов с блокировкой и скрытием карточек, журнал действий.

**Бот** присылает: снижение цены и новые акции у VPN из избранного, публикацию топа, статусы модерации владельцам. Сообщения идут через очередь (`notifications`) с ограничением скорости; если бот заблокирован пользователем, рассылка ему прекращается.

## Ключевые правила

| Правило | Как реализовано |
|---|---|
| Честная выдача | Сортировки и топ считаются только из отзывов, переходов и проверок. Таблица `ad_placements` для будущих рекламных мест отдаётся API отдельным полем `sponsored` и не участвует в ранжировании. |
| Отзыв только после перехода | `POST /api/services/:id/click` логирует переход с Telegram ID перед `openTelegramLink`; отзыв без записи в `clicks` отклоняется. |
| Топ-10 месяца | Сводный балл = 40% оценки за месяц (сглаженное байесовское среднее, чтобы один отзыв не решал) + 30% уникальные клиенты (нормированы к лидеру) + 30% доля пройденных ручных проверок. Веса — в `settings`, меняются в админке. Публикуется админом или автоматически 1-го числа в `TOP_AUTOPUBLISH_HOUR_MSK`. Архив — `top_snapshots` / `top_entries`, отсюда бейдж «Топ-10 за <месяц>». |
| Метка цены | Сравнивается цена за 1 месяц (или самый короткий тариф) со средней по видимому каталогу ±10%. Среднее пересчитывается при каждой публикации тарифов и при скрытии/возврате карточек. |
| Цены | Целые рубли, в `tariffs` хранится полная цена за период. |
| Модерация | Опубликованная версия живёт в `services`, правки — в `service_revisions` (новая отправка заменяет ожидающую). |
| Авторизация | `Authorization: tma <initData>`, подпись проверяется HMAC-SHA256 по токену бота, срок жизни — `INIT_DATA_MAX_AGE`. Роли — открытый список строк в `user_roles`, новые роли добавляются без изменений в авторизации и профиле. |

## Структура

```
server/
  index.js            запуск: HTTP, бот, планировщик
  app.js              маршрутизация, статика, webhook, заголовки безопасности
  auth.js             проверка initData, пользователи, роли
  db.js               схема SQLite и настройки по умолчанию
  routes/             public · me · owner · admin
  lib/catalog.js      каталог в памяти, фильтры, метка рынка
  lib/moderation.js   заявки, версии карточек, акции, отзывы, журнал
  lib/top.js          расчёт и публикация топа месяца
  lib/notify.js       очередь уведомлений и настройки
  lib/bot.js          Bot API: /start, кнопка меню, отправка
  lib/scheduler.js    снятие акций, автопубликация топа, отправка очереди
public/
  index.html, css/app.css, img/logo.svg
  js/dict.js          справочники (общие с сервером)
  js/tg.js            мост Telegram WebApp: MainButton, BackButton, haptics, ссылки
  js/views/           home · catalog · service · compare · favorites · profile · owner · admin · top
seed/seed.js          тестовые данные
test/                 node:test
```

## Этапы

1. ✅ Дизайн ключевых экранов (главная, каталог, карточка, сравнение, профиль) — в рабочем приложении.
2. ✅ Каталог, карточка, фильтры и сравнение на тестовых данных.
3. ✅ Кабинет VPN-сервиса и админка с модерацией.
4. ✅ Отзывы, избранное, уведомления.
5. ✅ Топ месяца, акции, метка цены относительно рынка.
6. ⏳ Наполнение первыми 20–30 реальными сервисами и запуск. Перед запуском: создать бота, задеплоить с HTTPS, **удалить тестовые данные** (`rm data/linza.db*` — все названия в сиде вымышленные) и пригласить владельцев VPN через «Добавить VPN».

## Заложено на следующие версии

- **Рынок услуг**: таблица `market_listings` (`kind`: `ad_channel`, `hosting`, `job`, `solution`), раздел «Скоро в Линзе» в профиле. Новые роли (исполнитель, владелец канала) — новые строки в `user_roles`.
- **Монетизация**: `ad_placements` (`catalog_top`, `collection_pin`, `highlight`, `home_banner`) с ценой и сроками; API уже отдаёт `sponsored` отдельно от выдачи. Реферальные ссылки — параметр `?start=` поддерживается в ссылке на бот. Платная верификация, продажа подписок и комиссии — после консультации с юристами.
